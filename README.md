# <h1 align="center">🎁 Amigo Secreto 🎁</h1>

<p align="center">
  Um projeto simples e divertido para sortear amigos secretos! 🎉✨
</p>

---

## 📌 **Como funciona:**

O Amigo Secreto é uma ferramenta fácil de usar para sortear nomes e celebrar a amizade. Siga os passos abaixo e divirta-se!

---

### **Passo 1: Insira os nomes dos amigos** 👥
- No campo de entrada, digite o nome de cada amigo que participará do sorteio.
- Clique no botão **"Adicionar"** para incluir o nome na lista.
- Repita o processo até que todos os nomes estejam na lista.

---

### **Passo 2: O programa sorteará um nome** 🎲
- Após adicionar todos os nomes, clique no botão **"Sortear amigo"**.
- O programa escolherá aleatoriamente um dos nomes da lista.

---

### **Passo 3: Descubra o amigo secreto!** 🎊
- O nome sorteado será exibido na tela.
- Agora é só comemorar e preparar um presente especial para o seu amigo secreto! 🎁🎉

---

## 🚀 **Recursos adicionais:**
- **Nomes únicos:** O programa não permite que nomes já sorteados sejam repetidos. 🔄
- **Sorteio justo:** Se o nome sorteado for o seu próprio, o programa sorteará novamente. 🤔➡️🎲
- **Interface simples:** Fácil de usar e perfeito para qualquer celebração. 🖥️✨

---

## 🛠️ **Como usar:**
1. Abra o arquivo `index.html` no seu navegador. 🌐
2. Siga os passos descritos acima. 📝
3. Divirta-se com o sorteio! 🎊

---

## 📝 **Exemplo de uso:**
1. Adicione os nomes: `Alice`, `Bob`, `Carol`, `David`. 👫👬
2. Clique em **"Sortear amigo"**. 🎲
3. O programa exibe: `Amigo sorteado: Bob`. 🎉
4. Bob é o amigo secreto de alguém! 🎁
